# E*NKI Avatar installé

Ouvrez ou rechargez le dashboard Hermes, puis choisissez l’onglet **E*NKI**.

Le plugin utilise la session et l’authentification du dashboard. Il ne demande ni clé API dans le navigateur, ni tunnel, ni serveur supplémentaire.

Au premier démarrage du mode conversation, autorisez simplement l’accès au microphone.
